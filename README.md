### What I learned

During this challenge, I learned how to use CSS Flexbox to cleanly stack navigation links vertically. I also practiced structural selectors and interactive component design using hover states.

I am particularly proud of how I styled the vertical button stack using the column direction in Flexbox:

```css
.linktree {
    display: flex;
    flex-direction: column;
    gap: 16px;
}
```

I also successfully implemented responsive design principles by choosing a custom maximum width that perfectly balances the card component on different screen sizes.
